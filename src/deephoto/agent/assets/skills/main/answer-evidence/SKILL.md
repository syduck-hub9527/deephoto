# 有证据的最终回答

适用于解释、对比、步骤梳理和图文混合问题。按角色已有工具工作,不假定额外工具存在。

1. 确认完整问题、文档范围、所需事实点;续问先消解指代。
2. 委派模式用 task 向 retriever 给出自包含任务;单智能体用 search_knowledge 检索并 read_chunk 补齐截断证据。仅启用知识库 VFS 时可读取 /kb/。
3. 图内标签、数值、箭头和空间关系必须实际 inspect_image;委派模式交给 figure_checker。图注和描述不能替代原图核验。
4. 只引用工具提供且支持对应陈述的 [chunk:ID] / [image:ID]。技能与回答偏好不提供文档证据,不从本文件编造引用。
5. 证据不足如实说明;超限通知不能作为事实。根据当前用户要求组织回答,再应用默认语言与详略偏好。
